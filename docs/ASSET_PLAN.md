# Asset plan — Cinematic Novel

## 01 Muralla → Puerta del Sol
- piedra/muro foreground
- vegetación lateral
- sombra de oclusión
- detalle de arco/puerta

## 02 Puerta del Sol → Plaza Mayor
- laterales del arco en primer plano
- piedra cercana
- luz de salida
- árbol/copa de entrada a plaza

## 03 Plaza Mayor → Catedral
- copa de árbol compartida
- hojas de primerísimo plano
- fachada lateral/máscara
- cielo de continuidad

## 04 Catedral → Ayuntamiento
- vegetación colgante trasera
- vegetación media
- hojas/lente foreground
- sombra suave de continuidad

## 05 Ayuntamiento → Acueducto
- árbol lateral
- fachada/arco de salida
- vegetación media
- piedra foreground

## 06 Acueducto → Parque
- ramas/pinos compartidos
- vegetación de ribera
- arco detalle para oclusión
- hojas desenfocadas

## 07 Parque → cierre / Alfonso VIII
- pinos oscuros
- roca/muro bajo
- vegetación foreground
- transición de luz hacia cierre

## Profundidad recomendada
- back: 0.08x–0.15x
- mid: 0.3x–0.5x
- foreground: 0.7x–1.0x
- lens/occluder: 1.15x–1.4x

Los valores son punto de partida; deben afinarse visualmente para evitar mareo.
